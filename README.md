# CampusSkill — Campus Peer-Learning Platform

CampusSkill is a campus-only platform where students teach each other skills, find peer tutors, swap knowledge and work together in study groups. Only `@srmap.edu.in` email addresses can sign up.

## Features
- **Profiles**: name, initials avatar, branch, year, bio, skills taught and wanted, average rating.
- **Find Tutors**: search by skill, filter by branch and year, send swap requests. You never see yourself in the results.
- **Skill swaps**: request → accept/reject (receiver only) → mark completed (either person) → rate 1–5 stars (requester only, once).
- **Study groups**: browse, search, filter by online/offline, create, join and leave. The creator is automatically a member and cannot leave. Groups can't go over their size limit.
- **Dashboard**: welcome message, skills, pending/completed counts, active groups, recent activity and a Recharts chart of your requests.
- **Admin dashboard**: totals, searchable user list, delete a user (with a confirmation box). Deleting a user also removes their related records, and an admin can't delete their own account.
- **UI**: indigo/purple design, sticky responsive navbar, toasts, confirmation boxes, loading skeletons, empty states, star ratings, form validation messages, and a dark mode toggle that remembers your choice.

## Technology stack
| Layer | Tech |
|---|---|
| Backend | Java 17, Spring Boot 3, Spring MVC, Spring Data JPA, Maven |
| Auth | HttpSession + BCrypt (no JWT) |
| Database | H2 (dev/test), PostgreSQL (prod) |
| Frontend | React, TypeScript, Vite, Tailwind CSS, Lucide icons, React Router, Recharts |

## Architecture
```
Browser (React SPA) --REST /api/**--> Controllers --> Services (rules) --> Repositories (JPA) --> H2 / PostgreSQL
      ^
      +-- served as static files by the same Spring Boot app (one port)
```
- `controller/`: REST endpoints (auth, users, skills, tutors, requests, groups, dashboard, admin, public preview).
- `service/`: all business rules (status changes, ratings, group capacity, admin checks).
- `repository/`: Spring Data JPA interfaces.
- `model/`: JPA entities for the six tables `users`, `skills`, `user_skills`, `swap_requests`, `study_groups` and `group_members`.
- `dto/`: request and response objects.
- `config/`: `AuthInterceptor` (protects `/api/**`), page-route forwarding, BCrypt, error handler and the demo `DataSeeder`.
- Every permission is checked on the server, not just in the UI.
- Page routes (`/dashboard`, `/groups/5`, …) forward to `index.html`, so refreshing a page works. `/api/**` is never intercepted.

## Run locally
Requirements: Java 17+, Maven 3.9+, Node 18+.

```bash
# 1. Build the frontend (outputs into src/main/resources/static)
cd frontend
npm install
npm run build
cd ..

# 2. Build and run the whole app (dev profile = H2 + demo data)
mvn clean package
java -jar target/campusskill.jar
```
Open http://localhost:8080.

**Frontend hot-reload (optional):** run `mvn spring-boot:run` in one terminal and `cd frontend && npx vite` in another. Then open http://localhost:5173 (`/api` is proxied to port 8080).

## Database configuration
- **dev** (default): H2 file database in `./data/`. Demo data is seeded when the database is empty. Delete `./data` to reset.
- **test**: in-memory H2, used by `mvn test`.
- **prod**: PostgreSQL. Set `SPRING_PROFILES_ACTIVE=prod`.

## Environment variables
| Variable | Purpose | Default |
|---|---|---|
| `PORT` | HTTP port | `8080` |
| `SPRING_PROFILES_ACTIVE` | `dev` or `prod` | `dev` |
| `SPRING_DATASOURCE_URL` | e.g. `jdbc:postgresql://host:5432/campusskill` | (prod, required) |
| `SPRING_DATASOURCE_USERNAME` / `SPRING_DATASOURCE_PASSWORD` | database login | (prod, required) |
| `COLLEGE_EMAIL_DOMAIN` | allowed signup domain | `srmap.edu.in` |
| `ADMIN_EMAIL` / `ADMIN_PASSWORD` | admin account created at start-up | dev: `admin@srmap.edu.in` / `Admin@123` |
| `SEED_DEMO_DATA` | seed demo data in prod | `false` |

## Deployment
**Docker (simplest):**
```bash
docker build -t campusskill .
docker run -p 8080:8080 \
  -e SPRING_DATASOURCE_URL=jdbc:postgresql://HOST:5432/campusskill \
  -e SPRING_DATASOURCE_USERNAME=... -e SPRING_DATASOURCE_PASSWORD=... \
  -e ADMIN_EMAIL=admin@srmap.edu.in -e ADMIN_PASSWORD=... campusskill
```
**Render / Railway / any Java host:**
- Build command: `cd frontend && npm ci && npm run build && cd .. && mvn -B package -DskipTests`
- Start command: `java -jar target/campusskill.jar`
- Set the environment variables above, with `SPRING_PROFILES_ACTIVE=prod`.

The app binds to `0.0.0.0` and reads `PORT`.
